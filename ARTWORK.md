# Artwork

The hero is an original illustration generated with the built-in imagegen tool for this redesign. It is promotional artwork, not a screenshot of the live voice room. The supplied avatar screenshot guided identity; the user's neon-city reference guided mood and scale. Neither reference screenshot is distributed in this repository.

Published assets:

- `assets/lapwing-night.webp`: 1672 × 941 primary artwork.
- `assets/lapwing-night-small.webp`: 1000 × 563 responsive version.
- `assets/social-cover.jpg`: social sharing preview.

Responsive image conversion only changes size/encoding; it does not modify the artwork.
