# Talking With Lapwing

Public landing page for **Lapwing** — an AI virtual streamer / AI VTuber.

Visitors can learn what Lapwing is, how the short browser voice chat works (~3 minutes, talk while listening, interrupt anytime), see the 18+ mic / on-stream note, and hop to JOIN plus Twitch, Discord, X, and Bluesky.

## GitHub Pages

This site is static: a single `index.html` at the repository root (plus this README).

**Serve from:** branch `main`, folder `/` (root).

Once Pages is enabled for the repo, the site is available at:

https://zhuyifeiabcd1.github.io/Talking-With-Lapwing/

No build step. Open `index.html` locally or let GitHub Pages serve it as-is.
